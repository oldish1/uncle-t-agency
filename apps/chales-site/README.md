# CHALES Hair Boutique website (chaleshairboutique.co.za)

Full copy of the live site, ready to deploy to Netlify as one folder.

- `index.html`: the home page (downloaded from the live site 4 Nov 2026, then edited). `index.live-2026-11-04.html` is the untouched original, kept as a backup.
- `nanoplastia/`, `keratin-brazilian-blowout/`, `hair-botox-glowtox/`, `hair-colour-highlights/`, `prices/`: treatment pages for Google. **Generated by `build_pages.py`.** Change prices, answers or photos in that script, then run `python3 build_pages.py`. Don't edit those pages by hand.
- `sitemap.xml`, `robots.txt`: generated by the same script.
- Opening hours are deliberately left off the new pages until Chanté confirms them (see `outputs/2026-11-04-chales-hours-fix-brief.md`). The home page still shows the old hours.

Deploy: the whole folder, via `scripts/deploy_netlify.sh` or Netlify drag-and-drop. Plan: `plans/2026-11-04-chales-google-page-one.md`.
