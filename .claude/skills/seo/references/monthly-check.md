# Monthly check template

First Monday of each month. Same searches every time, so changes mean something. Run each in Google, ChatGPT, Claude with web search on, and Perplexity or Gemini. Log: date, tool, search, was the business named (yes/no/position), who was named instead.

Swap the trade, suburb and services for the client. Hair salon example:

1. hair salon <suburb>
2. hair salon <neighbouring suburb>
3. <main service> <suburb>
4. <main service> <city>
5. <second service> <suburb>
6. <third service> <suburb>
7. <business has membership/offer?> in <suburb>
8. <Business name>

Also record from the owner's Google profile (Performance screen, screenshot): calls, direction requests, website clicks, messages, and from the booking system how many bookings came via each channel.

AI crawler notes: allow OAI-SearchBot (ChatGPT search), Claude-SearchBot (Claude search) and PerplexityBot in robots.txt. GPTBot and ClaudeBot are training crawlers and have no effect on search citations. llms.txt has no proven effect. Pages left untouched for six months lose citations, so refresh prices and dates monthly.

Targets belong to the client's plan. Never promise a position.
