# Start here

Four steps. Nothing else to read.

1. Put this folder somewhere sensible (your Desktop is fine). Name it after your company if you like.
2. Open the **Claude Desktop app**, click the **Code** tab, and open this folder. On Windows, install [Git for Windows](https://git-scm.com/download/win) and restart Claude if the Code tab asks for it.
3. Leave Claude's permission mode on **Auto** or **Ask permissions**. Approve actions as Claude explains them. Do not turn on Bypass permissions on a normal computer.
4. Type `/install` and press enter.

Claude takes it from there. The whole setup is a conversation: it asks, you answer, it builds. Set aside about three hours end to end, and pick a stretch where you can talk out loud. The longest part is the interview about your business, and that's the one worth not rushing, because everything else is downstream of it.

You need a paid Claude plan with access to Code. You do **not** need a GitHub account before you begin. The installer offers private backup later and lets you skip it.

You can stop at any point and pick up where you left off by typing `/install` again. It remembers how far you got.

You don't need to know how to code. You never will.

## Once you're set up, four things to remember

1. **`/prime`** at the start of every session. It loads your business back into Claude's head.
2. **Ask when you're stuck.** Plain English, no command needed. "How do I…", "can this even…", "I don't know what I'm doing here." Claude knows what's in this workspace and will pick the right tool and use it. This is the one people forget, and it's the one that matters most.
3. **`/handoff`** when a session gets long and starts to wander.
4. **`/log`** at the end, though it mostly runs itself.

The longer version is `reference/how-to-use-this.md`. You can also just ask for it.
