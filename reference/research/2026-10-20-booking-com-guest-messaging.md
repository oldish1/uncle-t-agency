# Booking.com guest messaging: can Uncle T Agency help hosts? (20 Oct 2026)

Why: Nita's Airbnb/Booking.com host clients (Fancy, Kobie, Megan) are overwhelmed by guest messages: fan, broom, blanket, extra towel, wifi, check-in.

## What we found
- **Booking.com's own Messaging API is closed to us.** It is only for certified Connectivity Partners (channel managers/PMS). An agency can't plug an AI straight into the Booking.com inbox. (developers.booking.com/connectivity/docs/messaging-api)
- **Booking.com already has free tools hosts under-use:** message templates, automatic replies, and a template scheduler in the extranet / Pulse app (Property > Messaging Preferences). Booking.com says 30%+ of partner replies are already automatic. (partner.booking.com, setting-templates-automatic-replies)
- **Paid AI tools exist** that answer Booking.com + Airbnb guests through a PMS: HostBuddy AI, Hospitable, Nowistay (from ~EUR 12/property/month), Akia, Conduit, Runnr.ai, Enso. All overseas, USD/EUR, need a PMS/channel manager set up, English-first support.
- **Commission:** Booking.com ~15% average (10-25%) on the full reservation incl. cleaning fee, plus 1.1-3.1% if using Payments by Booking.com. Airbnb now 15.5% host-only fee. (guesty.com, hostaway.com)
- Guests are used to hosts moving them to WhatsApp after booking (common practice; keep it to confirmed guests).

## Our angle
1. **Guest concierge on WhatsApp per host** (Luna for guests): QR code in the apartment + link in Booking.com's scheduled check-in message. Answers wifi, check-in, appliances, house rules, local tips 24/7; logs requests for extras (towel, blanket, fan, broom) and sends them to the cleaner/host as one daily list.
2. **Tie-in with Nita:** requests for extras/mid-stay cleans become paid jobs for Rags to Riches.
3. **Direct bookings (compete with Booking.com):** host website + WhatsApp booking for repeat guests, 0% commission. Win repeat guests, don't fight Booking.com for discovery.
4. Quick free win for every host: set up Booking.com auto-replies/scheduled templates for them.
