# CHALES new-client card

Business card, 90 x 50 mm, printed both sides. Files include 3 mm bleed (96 x 56 mm): tell the printer "90 x 50 with 3 mm bleed".

- **Front:** CHALES, Hair Boutique, treatments, gold band "10% off your first visit. New clients. Show this card when you pay."
- **Back:** QR code that opens WhatsApp to Lexi with "Hi Lexi! I got a CHALES card (GEN1) and I'd like to book." Address, Vodacom building, Lexi's number, website, hours.
- **Print file:** `chales-card-GEN1.pdf` (page 1 front, page 2 back).

## Tracking which places bring clients
Each place gets its own code (e.g. EP1 for a factory in Epping, PW1 for a shop in Parow). The code is printed small on the back and typed into Lexi's chat automatically, so Chanté can see which card a booking came from. GEN1 is the general card. Ask Claude for a new code per place; only the back changes.

## The 10% discount
Chanté gives it at the till when the client shows the card. Lexi doesn't apply discounts.
