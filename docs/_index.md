# Documentation Index

> Routing index for anything built in this workspace. Claude scans the conditions here and loads only the doc that matches what you're doing, rather than reading the whole folder every session.
>
> **Update rule:** change a system, update its doc. Build something new, create a doc and add a row here. Retire something, move its doc to `docs/archive/` and delete its row. All three happen through `/document`, so you shouldn't have to touch this file by hand.
>
> **Empty right now, and that's expected.** Rows appear as you build things.
